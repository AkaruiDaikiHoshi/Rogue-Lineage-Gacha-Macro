<h3 align="center">Instructions</h3>

    Open Gui, set up settings/webhooks. (Normal settings work but you do need a webhook url)
    Open Main
    Make sure roblox is full screened and is on 1 graphics.
    Be on the menu screen with roblox active, press F3 to start, F7 to stop.

----------------------------------------------------------------------------------
<h3 align="center">Settings Change</h3>

Some settings are not easy to change.

You can add more silver screenshots by:

    putting the amount of silver and then "silver" with no spaces
    like: 0silver, 250silver
    make sure it's somewhat similar to the screenshots I have already 
    
The added screenshots will be added onto the gui dropdownlist

You can add more scroll screenshots by:

    putting the name of the scroll and then "scroll" with no spaces
    like: hoppascroll, snarvscroll
    make sure it's somewhat similar to the screenshots I have already

The added screenshots won't be added onto the gui
but they will be detected by the macro
